# Go

The Go reference implementation of the Steno Encoding is the module `github.com/Singulink/Steno/Source/go`, with the package `steno`. It is portable scalar Go with word-at-a-time fast paths. It uses only the standard library, with no cgo and no `unsafe`, builds with Go 1.22 and later, and passes all test vectors of the specification.

### Installation

> [!NOTE]
> Not published yet: the module becomes available with the tag `Source/go/v1.0.0`.

```
go get github.com/Singulink/Steno/Source/go@v1.0.0
```

The last element of the import path is `go`, so import the package with a name:

```go
import steno "github.com/Singulink/Steno/Source/go"
```

## First Example

```go
b, err := steno.Encode("Москва")
if err != nil {
	panic(err)
}
s, err := steno.Decode(b)
if err != nil {
	panic(err)
}
fmt.Println(len(b), len("Москва")) // 7 12
fmt.Println(s)                     // Москва

// The bytes sort like the text, so a store can compare them without decoding.
zug, _ := steno.Encode("Zug")
zurich, _ := steno.Encode("Zürich")
fmt.Println(bytes.Compare(zug, zurich) < 0, "Zug" < "Zürich") // true true
```

Go compares strings byte by byte in UTF-8, which is code point order, so the order of Steno bytes under `bytes.Compare` is the order of the strings under `<`, `strings.Compare` and `sort.Strings`. The package needs no comparison functions of its own.

## What Is Particular to Go

| Feature | What it gives |
|---|---|
| Strings, runes and UTF-16 (`[]uint16`) | Go strings cannot hold a surrogate code point; runes and UTF-16 hold every value |
| `Append` functions | Append to a slice and return it, as `strconv.AppendInt` does. They leave the spare capacity after the appended bytes untouched, so data that another slice keeps there is safe, and on an error they return `dst` with its length and contents unchanged |
| `Encoder`, `Decoder`, `NewWriter`, `NewReader` | One value in pieces, and `io.Writer` and `io.Reader` adapters; `Flush` does not start a new value, `Reset` does. On invalid UTF-8, `Writer.Write` writes the text before the bad sequence and can be used again; `Writer.Close` checks that the text ended at the end of a UTF-8 sequence and does not close the underlying writer. A `Reader` returns the text before a bad code point, then the error |
| `*DecodeError` with `Reason` and `Offset` | The rule of the specification that the bytes break, and where |

The constant `steno.Name` is `x-steno`, the name to record next to the data.
