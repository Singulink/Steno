# Java

The Java reference implementation of the Steno Encoding is the Maven artifact `com.singulink:steno`, module `com.singulink.steno`. It is scalar Java with word-at-a-time fast paths. It has no runtime dependencies, needs Java 17 or later, and passes all test vectors of the specification.

## First Example

```java
import com.singulink.steno.Steno;

byte[] bytes = Steno.encode("Москва");
String text = Steno.decode(bytes);    // throws StenoDecodeException for invalid bytes

System.out.println(bytes.length);     // 7 (UTF-8 takes 12)
System.out.println(text);             // Москва
```

Compare the bytes as unsigned bytes with `Arrays.compareUnsigned`. For strings in memory, use `Steno.compareCodePoints` or `Steno.CODE_POINT_ORDER`: `String.compareTo` compares UTF-16 code units, which is another order where an emoji meets U+E000..U+FFFF.

## What Is Particular to Java

| Feature | What it gives |
|---|---|
| `StenoCharset` | The encoding as a `java.nio.charset.Charset` named `x-steno`, for `String.getBytes`, `new String`, readers, writers and every API that takes a charset |
| `Steno` | One-shot encode and decode, code point comparison, and helpers on encoded bytes |
| `StenoDecodeException` | The rule of the specification that the bytes break, and where; it extends `MalformedInputException` |

Two things follow from the Java charset API:

- **`new String(bytes, charset)` never throws**: it replaces invalid data. With `REPLACE`, which `new String`, `Charset.decode` and an `InputStreamReader` use, you get the text before the error and one U+FFFD, however the bytes arrive. Use `Steno.decode` when invalid data must be rejected.
- **A decoder that reported an error must be reset before it is used again.** After invalid data its state is unknown, so it drops every later byte without another report until `reset()`.
- **A charset encoder's `flush` ends the value**, as for every Java charset, and the encoder must be reset before it encodes again. `Writer.flush()` does not flush the encoder, so it can be called at any point of a stream.

`Steno.CHARSET_NAME` is `x-steno`, the name to record next to the data.
