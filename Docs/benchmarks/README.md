# Benchmarks of Steno

Generated by the benchmark tool (Benchmarks/Singulink.Steno.Benchmarks); do not edit by hand. To regenerate everything:

```
python Benchmarks/Singulink.Steno.Benchmarks/fetch_wikipedia.py <folder>    # once; the text is not in the repository
dotnet run -c Release --project Benchmarks/Singulink.Steno.Benchmarks -- report --wiki <folder> --wiki-date <date> --force
```

Without `--force`, the parts whose data files are in `data/` are kept, and the speed part goes on where it stopped; `--parts render` writes the fragments and charts again from the data alone.

Measured on 2026-11-21: AMD Ryzen 7 9700X 8-Core Processor, Microsoft Windows 10.0.26200, .NET 10.0.14 (X64).
