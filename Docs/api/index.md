# API References

Each implementation of the Steno Encoding has its API reference where developers in its language look for it. The [Implementations](../articles/implementations/dotnet.md) section has a page on each one, with its package and how to start.

| Implementation | Package | API reference |
|---|---|---|
| .NET | `Singulink.Steno` | [The `Singulink.Steno` namespace](Singulink.Steno.yml), on this site |
| Rust | `singulink-steno` | [docs.rs](https://docs.rs/singulink-steno), available once the package is published |
| C | `steno` (`steno.h` and `steno.c`) | The header [steno.h](https://github.com/Singulink/Singulink.Steno/blob/main/Ports/c/steno.h) in the repository |
| C library of the Rust implementation | `singulink-steno-capi` | The header [steno.h](https://github.com/Singulink/Singulink.Steno/blob/main/Ports/rust/capi/include/steno.h) in the repository: the same interface as the C implementation's first part |
| Go | `github.com/Singulink/Singulink.Steno/Ports/go` | [pkg.go.dev](https://pkg.go.dev/github.com/Singulink/Singulink.Steno/Ports/go), available once the package is published |
| Java | `com.singulink:steno` | [javadoc.io](https://javadoc.io/doc/com.singulink/steno), available once the package is published |
| TypeScript | `@singulink/steno` | Its [README](https://github.com/Singulink/Singulink.Steno/blob/main/Ports/typescript/README.md) documents the API |
| Python | `singulink-steno` | Its [README](https://github.com/Singulink/Singulink.Steno/blob/main/Ports/python/README.md) documents the API |

The .NET API is generated with this site: its namespace, `Singulink.Steno`, is in the table of contents of this page.
